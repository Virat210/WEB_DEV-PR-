**Short Explanation**
A linked list is a linear data structure made of nodes, where each node stores a value and a next pointer that connects it to the following node.
The head represents the starting point of the list.
Linked lists are useful because they allow fast insertions and deletions without shifting elements in memory.

## Methods Implemented

**Basic Methods:-**

addFirst(value):-
Inserts a new node at the beginning of the list.
The new node becomes the head, and its next pointer links to the previous first node.

addLast(value):-
Adds a new node at the end of the list.
The list is traversed until the last node, and the new node is attached after it.

deleteFirst():-
Removes the first node of the list.
The head is updated to point to the next node.

deleteLast():-
Deletes the final node in the list.
The second‑last node’s next pointer is set to null, removing the last node.

print():-
Displays all node values from head to tail in sequence.
Useful for checking the current structure of the list.

find(value):-
Searches the list for a specific value.
Returns true if the value exists, otherwise false.

delete(value):-
Removes the first node that contains the given value.
The list is scanned until the matching node is found and safely disconnected.
